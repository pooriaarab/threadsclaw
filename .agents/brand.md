This file records the facts implemented in `README.md`. The repository contains
no scraper code, archive format, interface, or deployment.

## Identity

- Repository name: `threadsclaw`
- Product description: Threads saved scraper
- Intended result: agent-friendly archives of saved Threads content
- Existing symbol: thread spool emoji, `🧵`

Use “ThreadsClaw” in prose when a readable product name is needed. Preserve the
lowercase `threadsclaw` form when referring to the repository.

## Promise

can use. Do not claim a current command, browser flow, authentication method,
schedule, archive schema, or export guarantee.

## Voice

result only when repository evidence supports them.

Do not describe the project as an official Threads product. Do not promise that
